# /orq-review

Run quality code review, refactoring, performance profiling, testing, and security auditing.

## Orchestration Pipeline

1. **Code Quality Refactoring via Prism**:
   - Inspect code smells, DRY principle violations, function size, and readability.

2. **Performance Optimization via Pulse**:
   - Profile query execution times, memory leaks, and Core Web Vitals.

3. **Automated Testing via Aegis & Echo**:
   - Generate unit, integration, and E2E test suites with high test coverage.

4. **Security Audit via Cyber**:
   - Scan for OWASP Top 10 vulnerabilities, input sanitization, and secret leaks.
