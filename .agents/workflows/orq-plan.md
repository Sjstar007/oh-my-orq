# /orq-plan

Run strategic planning and system architecture design for the user's prompt.

## Orchestration Pipeline

1. **Task Breakdown via Vector**:
   - Create a 3–7 stage execution roadmap with resource and token estimates.

2. **Risk & Plan Review via Aura**:
   - Evaluate dependencies, edge cases, potential bottlenecks, and risk factors.

3. **System & Data Architecture via Atlas & Nexus**:
   - Design high-level system architecture, Mermaid diagrams, SQL schemas, and REST/GraphQL API specifications.

4. **Plan Presentation**:
   - Present the validated technical plan to the user for review and approval.
