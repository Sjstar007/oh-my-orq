# /ultrawork

When the user activates `/ultrawork`, enter full autonomous execution mode:

## Workflow

1. **Analyze** the user's request completely
2. **Plan** via Vector — create a 3-7 stage execution plan
3. **Validate** via Aura — review the plan for issues
4. **Execute** each stage by delegating to the appropriate specialist:
   - Architecture → Atlas
   - Backend → Forge
   - Frontend → Nova
   - Testing → Aegis
   - Documentation → Quill
5. **Integrate** all results into a cohesive deliverable
6. **Review** via Ralph Loop — iterate until quality meets production standards
7. **Deliver** the complete solution

## Rules
- Do NOT ask the user for confirmation between stages
- Continue until the entire project is complete
- If a stage fails, retry with a different approach
- Track token usage for each stage
- Save key decisions to Project Cortex memory

## Output
Deliver a complete, working solution with:
- All source code files
- Tests with 80%+ coverage
- Documentation (README, API docs)
- Architecture decisions logged to memory
